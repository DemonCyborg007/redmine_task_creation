📋 CSV Format

  • RedmineID — Project ID
  • Tracker — Bug, Task, Feature, Change Request, etc.

  • Assignee — Team member name
  • Target version — Sprint/version name
  • Start date, Due date — Format: M/D/YYYY
  • Estimated time — Hours (e.g., 6, 8, 12)
  • Parent task — Parent issue ID (e.g., #104886)
